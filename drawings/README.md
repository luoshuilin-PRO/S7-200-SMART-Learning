## 两张图怎样读

上半部从+24V沿线经过S0停止常闭触点、S1常开按钮到K1线圈A1，再由A2回0V。所有实体触点按未操作、线圈未得电状态绘制。图中的线和圆点表示连接；下半部PLC图是另外一种逻辑实现，不与上半部混接。

点动没有保持支路；自锁的K1辅助常开触点与S1并联，S0在两条支路外侧，所以停止可以切断整个回路。停止与启动同时按下时K1释放；若启动一直按住再释放停止，K1会重新吸合，基础回路不具有防重启功能。

| 标号 | 名称 | 端子/作用 |
|---|---|---|
| -S0 | 停止按钮，常闭NC | 11–12，按下断开 |
| -S1 | 点动/启动按钮，常开NO | 13–14，按下闭合 |
| -K1 | 24V DC继电器 | A1/A2线圈 |
| -K1 13–14 | 同一继电器的辅助常开触点 | 仅自锁图有，用于物理保持 |
| I0.0 | PLC启动/点动输入 | 现场常开按钮，按下=1 |
| I0.1 | PLC停止允许输入 | 现场常闭按钮，正常=1；图中用程序常开触点读取 |
| Q0.0 | PLC运行指示灯输出位 | 自锁图中另用同名程序触点保持 |

实体K1触点反映继电器机械状态；PLC的Q0.0程序触点读取输出位，不证明继电器已吸合。尚未指定CPU型号，故没有猜测PLC公共端、晶体管/继电器输出接法、端子排或电机动力回路。

## 实物实施前补齐

此图用于理解控制关系。需根据实际电源、继电器额定电流、按钮及导线配置过流保护；直流线圈按厂商要求配置抑制器件并核对极性。电机必须另配接触器、短路/过载保护及适用的安全回路。S0普通停止按钮不等于安全急停。
