## 示例约定

I0.0 为常开启动/点动按钮，按下为 1；I0.1 为常闭停止按钮输入，未按下为 1、按下或断线为 0；Q0.0 为运行指示灯。地址仅为练习示例，应以实际 CPU 与接线为准。

ASCII 梯形图用于解释逻辑，不是可直接下载的 Micro/WIN SMART 工程。本仓库暂不包含原生工程文件。先用指示灯验证；电机应经匹配的驱动/接触器及保护回路控制，普通 PLC 程序不能替代急停安全回路。
